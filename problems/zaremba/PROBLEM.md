# Zaremba's Conjecture

> **Tier 0.** Published background only. Nothing below reflects what this lab
> has tried. See `AGENTS.md`.

**Statement.** For a reduced fraction m/n (0 < m < n, gcd(m, n) = 1) let

    m/n = [0; a₁, a₂, …, a_k] = 1/(a₁ + 1/(a₂ + ⋯ + 1/a_k))

be its canonical continued fraction, with the convention a_k ≥ 2. This is the
expansion the Euclidean algorithm produces, and it is unique. Write
K(m/n) = max_i a_i, and define

    z(n) = min { K(m/n) : 1 ≤ m < n, gcd(m, n) = 1 },   z(1) = 1.

**Zaremba's conjecture** (1971): z(n) ≤ 5 for every n ≥ 1.

Motivation: pairs (m, n) with small K(m/n) are the "good lattice points" of
quasi-Monte Carlo integration — the two-dimensional lattice rule generated by
(1/n)(1, m) has discrepancy O(K(m/n) · log n / n), so the conjecture asserts
that an essentially optimal generator exists for every modulus n.

## Published status

- Open in general. Bourgain–Kontorovich (Ann. of Math. 2014) proved the
  density-one version for the alphabet {1, …, 50}: the set of n admitting a
  witness m with all partial quotients ≤ 50 has natural density 1. Huang
  (GAFA 2015) improved the alphabet to the conjectured {1, …, 5}: almost every
  n satisfies Zaremba's conjecture as stated. The exceptional set is o(N), not
  known to be empty. Related refinements: Frolenkov–Kan, Kan, Magee–Oh–Winter.
- Niederreiter (1986) proved the conjecture for n = 2^j and 3^j (with partial
  quotients ≤ 3) and for n = 5^j (with ≤ 4).
- The bound 5 is attained: z(6) = 5, since the only reduced fractions with
  denominator 6 are 1/6 = [0; 6] and 5/6 = [0; 1, 5].
- Hensley (1996) conjectured a stronger dimension criterion: for any finite
  alphabet 𝒜 whose continued-fraction Cantor set has Hausdorff dimension
  > 1/2, every sufficiently large n is a denominator with partial quotients
  in 𝒜. This is **false as stated**: the alphabet {2, 4, 6, 8, 10} has
  dimension ≈ 0.517, yet its denominators avoid the residue class 3 mod 4.
  Bourgain–Kontorovich formulate a corrected local–global version.

## Verification contract

What a claim about this problem has to do to be checkable:

- **Convention first.** All partial-quotient claims here use the canonical
  expansion (last quotient ≥ 2). The alternate expansion […, a_k − 1, 1] can
  *lower* the maximum when the unique maximum is the last quotient, so mixing
  conventions silently changes z. Any deviation must be stated.
- **Witness claims ship the witness.** "n satisfies Zaremba" means a concrete
  m; checking it is one run of the Euclidean algorithm
  (`harness/zaremba/zaremba.py verify <n> <m>`).
- **A scan is `EVIDENCE` bounded by its range.** "z(n) ≤ 5 for all n ≤ N"
  states N and ships the command that reproduces it.
- **An exact value z(n) = v needs two halves:** a witness with K = v, and an
  exhaustive scan over all coprime m showing nothing below v. Everything is
  integer arithmetic; floating point never enters.
- **Independent verification means a different algorithm** — e.g. forward
  generation of bounded-quotient fractions via continuants against per-pair
  Euclid — not a re-run of the same code.
