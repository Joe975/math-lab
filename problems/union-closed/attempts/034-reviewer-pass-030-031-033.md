### R1 — (HU-TAX at p̄) is false for every p̄ < 1/4, and its stated equality case is the counterexample

031 poses, for every p̄ < 1/2,

    (HU-TAX at p̄):  CR_HU(μ) ≥ ((1−h(p̄))/h(p̄))·H(μ) for all μ with
    element marginals ≤ p̄, "with equality exactly at Bern(p̄)^⊗n".

Take μ = Bern(p)^⊗n. Every HU cell has x = y = 1−p, so

    z = min(max(1/2, 1−2p), 1−p),  CR_HU = n(h(z) − h(p)),  H = n·h(p).

For p ∈ [1/4, 1/2] the Fréchet floor is idle, z = 1/2, and
CR_HU = n(1−h(p)) — equality, as the record says. For **p < 1/4** the
floor bites, z = 1−2p, and

    CR_HU/H = (h(2p) − h(p))/h(p) < (1 − h(p))/h(p)

**strictly**, because h(2p) < 1 for every p < 1/4. The deficit is exactly
n(1 − h(2p)) bits. Smallest hand-checkable witness: p̄ = 1/5, n = 1,
CR_HU = h(3/5) − h(1/5) = 0.249022, RHS = 1 − h(1/5) = 0.278072, deficit
1 − h(2/5) = 0.029049 (exact rationals, 60-digit `Decimal`;
`uc_reviewer034_reimpl.py` P6). At n = 4: violations at
p̄ = 0.05/0.10/0.15/0.20/0.24 with CR−RHS = −2.124/−1.112/−0.475/−0.116/
−0.0046, equality at p̄ = 0.25, equality again at 0.30 and 0.38271.

The kill is order-independent (products are exchangeable), so it takes
the identity-order and best-order forms with it — 033's surviving
"identity/best-order forms unrefuted everywhere tested" is true only of
the ranges 033 tested (caps ≥ 0.38271), not of the conjecture's own
quantifier.

**Corrected statement.** The sharp product constant is

    c*(p) = (h(min(2p, 1)) − h(p))/h(p),

which equals (1−h(p))/h(p) exactly on [1/4, 1/2) and is strictly smaller
below 1/4. (HU-TAX at p̄) should be posed only for **p̄ ∈ [1/4, 1/2)**
(and, per 033, with an order convention). Nothing load-bearing moves:
the working cap 0.38271 and every cap swept in 031/033 lie in
[1/4, 1/2), 030's HU-mix hypothesis (all components in [1/4, 1/2])
forces p̄ ≥ 1/4 by itself, and the cap-form of the conjecture — the one
the sweeps actually test, with p̄ fixed at the cap rather than at each
instance's own marginal — is untouched (Bern(0.2)^⊗4 has
CR/H = 0.345 ≫ 0.041739). What moves is the *shape* of the target for
queue (b): the extremal constant is a two-branch function of p̄, and the
[1/4, 1/2) restriction is not cosmetic — it is exactly where the HU
clamp is idle, which is also exactly the hypothesis 030 needs.

**Why the campaigns missed it.** 031 §3 and 033 both compare an
instance's CR/H against (1−h(cap))/h(cap), never against
(1−h(marg(μ)))/h(marg(μ)); and every scan projects measures *up* toward
the cap. The sharp-p̄ form was therefore never evaluated at a low-marginal
instance.

### S1 — mini-theorem HU-mix (030): re-derived by hand, correct, and its hypothesis is tight

Attack: re-derive the proof from scratch, then look for a component
range where the argument leaks.

Given the shared label k, the per-coordinate joint of component k has
both-zero probability 1/2; the Fréchet window for a Bern(p) product is
[max(0, 1−2p), 1−p], which contains 1/2 **iff p ∈ [1/4, 1/2]** — so the
hypothesis is exactly the feasibility condition, not a convenience. In
any history cell the conditional both-zero probability is the posterior
mixture over k of the constant 1/2, hence 1/2, so Σᵢ E[h(zᵢ)] = n
exactly and CR = n − H(μ). The U-side remark also checks out: given k
the Uᵢ are independent Bern(1/2), so U ~ Unif(2^[n]) for each k and
hence unconditionally — I confirm H(U) = n to 1e-12 at n = 2, 4, 6.
Then H(μ) ≤ Σᵢ h(margᵢ) ≤ n·h(p̄) (subadditivity + h increasing on
[0,1/2]) gives CR = n − H ≥ n(1−h(p̄)) ≥ ((1−h(p̄))/h(p̄))·H(μ), the last
step using n ≥ H/h(p̄) and 1−h(p̄) > 0. **Sound.** Note also that
p̄ ≥ 1/4 is forced by the hypothesis, so R1 cannot touch this theorem.

I also checked the sharper claim 031 attaches to it — that on this
sub-genre the HU coupling *itself* (history conditionals, not
per-component ones) has an idle clamp: with all p_k ≤ 1/2 every cell has
x, y ≥ 1/2, and with all p_k ≥ 1/4 every cell has x, y ≤ 3/4, so
x + y − 1 ≤ 1/2 ≤ min(x, y) and z = 1/2 always. Both ends of [1/4, 1/2]
are load-bearing. **Correct as stated.**

Constants: (1−h(0.38271))/h(0.38271) = 0.0417387795 (031/030 quote
0.041739 ✓); CR_HU(Bern(p)^⊗n) = n(1−h(p)) verified to 1e-9 at
p ∈ {0.25, 0.3, 0.38271, 0.45} — and, per R1, *only* for p ≥ 1/4.

### S2 — Lemma HU-notax (031), including the per-cell sign analysis

Attack: verify the σ-field argument, then test the sign claim on the
branch the record compresses into one clause.

Each HU cell joint's A-margin is μ(A_i = 0 | a) for **every** partner
history b, so the conditional x̃ᵢ is A_{<i}-measurable and
Σᵢ E[h(x̃ᵢ)] = Σᵢ H(A_i | A_{<i}) = H(μ); same for B. Hence
T_A = T_B = 0 and CR_HU = Σᵢ E[h(zᵢ)] − H(μ) = Σᵢ E[h(zᵢ) −
(h(xᵢ)+h(yᵢ))/2] identically. Numerically: |T_A|, |T_B| ≤ 8.9e-16 and
|ledger − CR| ≤ 1e-15 at all five floor instances (own evaluator).

The sign analysis is correct, and the branch flagged in the brief is
covered:
- both x, y ≥ 1/2 and x+y ≤ 3/2: z = 1/2, h(z) = 1 ≥ avg. ✓
- both x, y ≥ 1/2 and x+y > 3/2: the Fréchet floor x+y−1 exceeds 1/2,
  so z = min(x+y−1, x, y) = x+y−1 (since x+y−1 ≤ x ⟺ y ≤ 1), and
  1/2 ≤ z ≤ min(x, y); h is decreasing on [1/2, 1], so
  h(z) ≥ max(h(x), h(y)) ≥ avg. ✓ **The z = x+y−1 branch is genuinely
  covered, not just the z = 1/2 one.**
- mixed (x < 1/2 ≤ y): x+y < 3/2 so z = min(1/2, x) = x = min(x, y);
  term = (h(x)−h(y))/2, of either sign.
- both below 1/2: z = min(x, y); term = −|h(x)−h(y)|/2 ≤ 0.
  So "deficit cells ⊆ mixed ∪ both-below" is right; note (worth
  recording for queue (b)) that in *every* clamped cell z = min(x, y),
  so the whole deficit is Σ E[h(min(x,y)) − (h(x)+h(y))/2] over clamped
  cells.
