[D-AC] On the DEATH segment prove, for every integer s with 1 <= s <= a-1:  sin(beta(t)) * sin(2sA + t(a+2b+1-2s)) > N2(t)[death]  for all t in the death range. Note the left sine's argument lies in (2A - small, 180 - 2A + small); the dangerous cases are s = 1 and s = a-1 where sin(2sA) ~ sin(2A). Hint that may help: N2 <= sin(at)*sin(theta), and sin((b+1)beta(t)) = cos(A - 2(b+1)t).
[D-AB] On the DEATH segment prove, for every integer s with 1 <= s <= a-1:  sin(theta(t)) * sin((2s-1)A + t(a+2b+2-2s)) > N2(t)[death], equivalently (dividing by sin(theta) > 0)  sin((2s-1)A + t(a+2b+2-2s)) > sin(at) sin((b+1)beta(t)).  The s = a case equals the PB > 0 condition and is already handled; do NOT spend effort there.
[D-BC] On the DEATH segment prove, for every integer j with 1 <= j <= b-1 (empty if b = 1; then just say so):  sin(alpha(t)) * sin(90 - at + (b-2j)beta(t)) > PB(t)[death].  Write sin(90 - at + (b-2j)beta) = cos(at - (b-2j)beta) and use (b-2j)beta(t) = (b-2j)(bc + 2t).
[D-BA] On the DEATH segMENT prove, for every integer j with 1 <= j <= b:  sin(aalpha(t) + (b+1-2j)beta(t)) > cos((b+1)beta(t)) sin(aalpha(t))  where aalpha(t) = 90 - at.  (The factor sin(theta) has already been cancelled from both sides; the right side equals [sin(aalpha+(b+1)beta) + sin(aalpha-(b+1)beta)]/2 by product-to-sum, which may give a clean route.)
[D-N1] On the DEATH segment with the range 0 < t <= 45 k/(a(b+1)), prove N1(t) := cos(at) sin(beta(t)) sin((2b+1)t) - sin(at) sin(alpha(t)) sin(b beta(t)) > 0.  Sub-goal (i), needed first and independently valuable: prove (2b+1) sin(bc) > a sin(A) sin(b bc) for all a >= b >= 1, a >= 2 (this is N1'(0) > 0 up to positive factors).  Sub-goal (ii): extend to the whole t range, e.g. via monotonicity or a term-by-term comparison. This is the hardest task in the batch; partial results with exact statements are welcome.
[B-AC] On the BIRTH segment prove, for every integer s with 0 <= s <= a-1:  sin(beta(t)) * sin((2s+1)A + t(a-b-2-2s)) > N2(t)[birth].  Note at s = 0 the left argument is A + t(a-b-2) and the inequality is tightest; for the general s the argument lies well inside (0,180).
[B-AB] On the BIRTH segment prove, for every integer s with 1 <= s <= a-1:  sin(2sA + t(a-b-1-2s)) > sin(at) cos((b+1)t).  (The s = a case is exactly the sine addition formula sin(t(a+b+1)) = sin(at)cos((b+1)t) + cos(at)sin((b+1)t) > sin(at)cos((b+1)t) and is already done; do not repeat it.)
[B-BC] On the BIRTH segment prove, for every integer j with 0 <= j <= b-1:  sin(alpha(t)) * cos((b-2j)Bh - t(a+b-2j)) > PB(t)[birth].  At j = 0 use cos(b Bh - t(a+b)) = sin(Bh + t(a+b)); the j = 0 case is the tightest.
[TAU] Let mu = exp(2i(-a alpha + (b-1) beta)) (angles in degrees inside the exponential as i*pi/180*(...)), delta with delta^2 = mu, w = sin(alpha+beta) * (1 + exp(-2i(a alpha + beta)) - mu - exp(-2i beta)), tau = w + mu conj(w).  Derive a REAL closed form (product of sines/cosines of integer combinations of alpha, beta, a alpha, b beta) for  R := Re( conj(delta) tau ), simplify it as far as you can, and determine its sign on both the DEATH and BIRTH segments for the stated t ranges. Show every algebraic step.
[T2] BIRTH-SIDE NECESSITY, case-tree skeleton. Suppose 0 < alpha, 0 < beta, alpha + beta < 90, and ALL of the following hold (the "alive" margin system): (i) cos(a alpha) sin((b+1)beta) > 0 and cos((b+1)beta) sin(a alpha) > 0; (ii) for s = 0..a-1: cos(a alpha) sin((b+1) beta) sin(alpha+beta) + sin(beta) sin((a-2s-1) alpha - (b+1) beta) < 0; (iii) for s = 1..a: cos(a alpha) sin((b+1)beta) sin(alpha+beta) + sin(alpha+beta) sin((a-2s) alpha - (b+1) beta) < 0; (iv) for j = 0..b-1: sin(alpha) sin(a alpha + (b-2j) beta) > cos((b+1) beta) sin(a alpha) sin(alpha+beta); (v) for j = 1..b: sin(alpha+beta) sin(a alpha + (b+1-2j) beta) > cos((b+1) beta) sin(a alpha) sin(alpha+beta).  GOAL: prove a alpha < 90 and (b+1) beta < 90, hence alpha + beta < 90/a + 90/(b+1).  The danger is higher branches (e.g. a alpha in (360,450)); show the fan conditions (ii)-(iii) exclude them: as s runs 0..a the angles (a-2s)alpha sweep an arithmetic progression with gap 2 alpha, and a single-signed sinusoid pattern over a progression crossing the circle is impossible. Make that pigeonhole precise, or find the precise obstruction to it.
